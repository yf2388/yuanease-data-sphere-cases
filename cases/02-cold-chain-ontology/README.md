# 案例 02 · 冷链门店本体：库存、冷柜遥测与货运

> 场景参考自 Microsoft Fabric IQ 本体（Ontology）教程「Lakeshore Retail」（<https://learn.microsoft.com/en-us/fabric/iq/ontology/tutorial-0-introduction>）。
> 本案例只复现其业务场景与问题；数据来自 microsoft/fabric-samples 仓库（MIT 许可），表名与列名已译为中文；教程文字、截图均为本仓库自行撰写与拍摄。

## 场景

一家区域零售企业经营冷冻、易腐与常温商品，门店由区域配送中心补货，冷冻品存放在门店冷柜里，冷柜每 5 分钟上报一次温度。门店运营要同时盯住三件事：冷冻品是否低于安全库存、冷柜温度是否越界、货架可得率是否达标，并且知道下一批货什么时候到。

原教程最终要回答的问题是：「西部区域的一级门店里，哪些门店同时存在冷冻品低于安全库存、冷柜温度异常、货架可得率低于目标？各自下一批到货的预计时间是什么？」本案例第 10 题就是这个问题。冷柜与遥测的结构与工厂里的「设备 + 传感器」完全一致，可以直接套用到车间设备监控。

## 你将完成

1. 新建资料库并上传 7 张表格。
2. 让数字员工「BI 分析师」构筑实体模型：识别实体、唯一标识列、表与表之间的关系，以及常用指标。
3. 审核员工识别出的关系并发布。
4. 用自然语言问 10 个业务问题，与下方标准答案逐题核对。

预计用时约 25 分钟。

数据要点：

- 「地点」表同时包含门店（STORE）与配送中心（DC），由「地点类型」区分；原教程用实体继承表达，本产品用一张表一个实体加类型列表达。
- 「库存」是一次快照（同一快照时间），门店编号 + 产品编号唯一定位一行；「库存状态」0 表示有风险、1 表示健康。
- 时间均为原数据的 UTC 时间。

数据来源与改动：取自 microsoft/fabric-samples 仓库 `docs-samples/iq/ontology/new-experience` 下的 7 个 CSV；表名、列名译为中文；布尔值写成「是/否」；时间写成「YYYY-MM-DD HH:MM:SS」；不含 SalesReport.pbix（原教程用它建「销售」实体）。

## 操作步骤

### 0. 准备

- 安装并登录 Yuanease 桌面应用（版本 0.8.7 或更高）。
- 下载本仓库：`git clone <仓库地址>`，或在仓库页面下载 ZIP 后解压。本案例的数据在 `cases/02-cold-chain-ontology/data/`。

### 1. 新建资料库

左侧导航进入「资料库」，点右上角「新建资料库」。名称填「案例02 冷链门店本体」，描述可选填，范围与权限保持默认，点「创建资料库」。

![新建资料库](images/1-new-kb.jpg)

### 2. 上传表格

在新资料库里点右上角「添加」→「表格」，点「点击上传、拖拽或粘贴文件」，选中 `data/` 目录下全部 7 个文件，再点「开始索引 7 个文件」。全部变为可查询后关闭对话框。

![选择表格](images/2-upload.jpg)

### 3. 构筑实体模型

切到「实体模型」页签，点「构筑实体模型」。向导默认选中全部表格，保存位置为新建文件夹「实体模型」，由「BI 分析师」构筑。保持默认，点「开始构筑」。

![构筑向导](images/3-build-wizard.jpg)

构筑在后台运行，可以关闭窗口，进度显示在左侧线程「实体模型 · 案例02 冷链门店本体」里。

![构筑进行中](images/4-build-running.jpg)

### 4. 回答员工的提问

员工会把从数据里看不出业务含义的地方集中问你一次。了解业务就直接回答（可参考上方「数据要点」）；不确定就回答「不知道，请你按数据自己判断。」，本案例的实测成绩按这个回答得到。填好后点「提交并继续」。

本案例实测员工问了 5 个问题：库存状态 0 / 1 各表示什么、货运状态三个取值的含义、地点类型 DC 是否指配送中心、几组跨表对应关系是否成立、传感器状态是否还有别的取值。可以这样回答：「库存状态 0 表示有风险，1 表示健康；PLANNED / IN_TRANSIT / DELIVERED 分别是计划中、在途、已送达；DC 是配送中心，门店指标只算 STORE；这些对应关系都成立。」

![员工提问](images/5-employee-question.jpg)

### 5. 审核关系并发布

构筑完成后回到资料库的「实体模型」页签，点「去审核」。左侧逐条列出员工识别出的关系，以及关联字段和取值重合率。

本案例员工识别出 8 条关系，取值重合率都是 100%，逐条点「成立」即可。

全部处理后点右下角「发布」。

![审核关系](images/6-review.jpg)

![发布完成](images/7-published.jpg)

### 6. 问数

在资料库顶部点「智能问答」，输入框上方会显示「针对 案例02 冷链门店本体 回答」。逐题输入下方表格里的问题，与标准答案核对。如果员工先弹出卡片请你确认指标口径，确认无误后选「确认」继续。

![问数结果](images/8-qa.jpg)
